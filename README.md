<h1 align="center">Vanish</h1>

<p align="center">
  Windows 앱과 남겨진 흔적까지 깔끔하게 정리하는 앱 제거 도구
</p>

## 소개

Vanish는 설치된 앱을 제거하고, 삭제 후에도 남을 수 있는 파일과 레지스트리 항목을 함께 찾아 정리합니다. 일반 데스크톱 앱과 Microsoft Store 앱을 한곳에서 확인할 수 있으며, 필요한 데이터는 삭제 전에 백업할 수 있습니다.

## 주요 기능

- 설치된 데스크톱 앱 및 Microsoft Store 앱 조회
- 앱 이름과 제조사로 빠른 검색
- 바탕 화면 바로가기 또는 실행 파일을 끌어 놓아 앱 찾기
- 삭제 전 관련 파일과 레지스트리 항목 확인 및 선택
- 앱 데이터 백업 및 복원 (`.appbak`)
- 휴지통을 이용한 안전한 정리와 선택적 영구 삭제
- 삭제가 필요한 순간에만 관리자 권한 요청

## 안전한 삭제

Vanish는 앱이 제공하는 공식 제거 프로그램을 우선 사용합니다. 추가로 선택한 잔여 파일은 기본적으로 휴지통으로 이동하며, Windows 핵심 경로는 보호 대상에서 제외합니다.
